# NEWS-APPLICATION
This is a simple web app built with React and Vite that allows users to read news articles.

## FEATURES
- View a list of news articles. 
- Search for news articles with title and author name.
- Read full news articles.
- Add new article. 
- Edit existing articles.
- Delete articles.

## MAIN TOOLS
- React 
- JavaScript
- Vite
- Tailwind CSS.

## INSTALLATION
- Clone the repository: 
git clone https://github.com/This-Bilal/News-Application.git
- Navigate into the project folder: 
cd News-Application 
- Install dependencies: 
npm install

## PROJECT RUN
Start the server: npm run dev. The app will run on localhost:5173.


NOTE: This project is for learning purposes and demonstrates CRUD (Create, Read, Update, Delete) functionality using React.
